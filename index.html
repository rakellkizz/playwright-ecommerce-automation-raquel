Sobre o projeto

🎯 Objetivos

  • Demonstrar práticas de automação de nível E2E com Playwright.
  • Criar cenários de fluxo completo (login, carrinho, compra, perfil).
  • Login com sucesso e com falha.
  • Ação de manter itens no carrinho.
  • Validação de mensagens de erro visuais.
  • Busca com sugestões e detalhes de produto.
  • Execução em paralelo e smoke tags.
  • Execução em perfil desktop e mobile.

🧠 Stack técnica

  • Playwright Test (Node.js).
  • Teste via selectors estáveis.
  • Relatório oficial HTML.
  • Vídeos, screenshots e traces.
  • Execução em pipeline CI.
  • Branch gh-pages dedicada a relatórios.
  • Publicação via GitHub Pages.

Cenários cobertos

🔐 Login

Fluxo de login completo, erros visíveis e bloqueio progressivo.

📄 Detalhes técnicos do cenário
  • Validação de credenciais incorretas.
  • Mensagens de erro visíveis e acessíveis.
  • Tempo de resposta da API de autenticação.
  • Bloqueio progressivo após tentativas inválidas.

🛒 Carrinho

Adicionar, remover, manter estado e validar total do carrinho.

📄 Detalhes técnicos do cenário
  • Persistência dos itens no localStorage.
  • Cálculo de totais, descontos e frete.
  • Sincronização entre desktop e mobile.

📦 Checkout

Endereço, pagamento, revisão e confirmação final.

📄 Detalhes técnicos
  • Validação de endereço e CEP.
  • Integração com gateway de pagamento.
  • Retentativas automáticas em falhas temporárias.

🔎 Busca

Pesquisa gradual, filtros e ordenação.

📄 Detalhes técnicos
  • Busca dinâmica enquanto digita.
  • Sugestões vindas da API.
  • Aplicação simultânea de filtros.

🧪 Smoke Tests

Fluxo principal em poucos passos.

📄 Detalhes técnicos
  • Autenticação.
  • Adicionar item e finalizar compra.
  • Confirmação de pedido.

👤 Perfil

Edição de dados e validações de sucesso.

📄 Detalhes técnicos
  • Validação de campos obrigatórios.
  • Integração com API de perfil.
  • Sincronização com sessão autenticada.
